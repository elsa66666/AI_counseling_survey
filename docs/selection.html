03 / BOUNDARIES

Apply the same rule to every contribution

  • Implemented role: a proposed or specifically adapted counselor/support model or interactive client model qualifies.
  • Resource + model: a dataset paper with a trained support model qualifies; a standalone resource is supporting literature.
  • Evaluation + client: a benchmark with a dedicated interactive client policy qualifies. Testing stock models alone does not.
  • Offline reconstruction: generating a complete transcript or filling masked utterances is corpus construction, not an interactive client simulator.
  • Auxiliary tools: unchanged reused simulators do not add a new client-model contribution to a counselor paper.
